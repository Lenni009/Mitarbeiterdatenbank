db.csv Inhalt:
Mustermann,Max,01234,123,0

Musterfrau,Erika,09876,987,0

Happy Path (gültige Eingaben, erwartetes Nutzerverhalten):
- Datenbank ansehen:
  Mitarbeiternummer: 0
  Name: Mustermann
  Vorname: Max
  PLZ: 01234
  Gehalt: 123
  Jahre der Betriebszugehörigkeit: 0

  Mitarbeiternummer: 1
  Name: Musterfrau
  Vorname: Erika
  PLZ: 09876
  Gehalt: 987
  Jahre der Betriebszugehörigkeit: 0

- Mitarbeiter*in hinzufügen:
  - Vorname: John
  - Name: Doe
  - PLZ: 45678
  - Gehalt: 100000
-> Mitarbeiter*in John Doe mit der Mitarbeiternummer 2 erfolgreich hinzugefügt

- Mitarbeiter*in bearbeiten:
  - Mitarbeiternummer: 1
    - Gehalt erhöhen
      -> Gehalt erfolgreich erhöht (neuer Wert 1184.4)
    - Jahre der Betriebszugehörigkeit erhöhen
      -> Jahre der Betriebszugehörigkeit erfolgreich auf 1 erhöht
    - Mitarbeiter*in entfernen
      -> Mitarbeiter*in erfolgreich entfernt

Zwischenschritt: Betriebszugehörigkeit von Mitarbeiternummer 2 erhöhen

- Mitarbeiter*in suchen:
  - Mit Name:
    - Vorname: Max
    - Nachname: Mustermann
      -> Folgende Mitarbeiternummern sind mit dem Namen Max Mustermann assoziiert:
         0
  - Mit Jahren der Betriebszugehörigkeit:
    - 1
      -> Folgende Mitarbeiternummern haben 1-jähriges Jubiläum:
         2

- Programm beenden
  -> Exit Code 0


Unhappy Path:
- float / char / out of range int Eingabe in Menü -> "Ungültige Option"
- char in PLZ -> nicht validiert, wird in Datenbank geschrieben
- PLZ zu kurz -> nicht validiert
- PLZ zu lang -> automatisch auf 5 Stellen gekürzt
- char als Gehalt -> Gehalt wird 1 -> Kann danach noch geändert werden
- negatives Gehalt -> Vorzeichen wird ignoriert
- out of range Mitarbeiternummer in Mitarbeiter*in bearbeiten Menü -> "Ungültige Mitarbeiternummer"
- Faktor 0 für Gehaltserhöhung -> "Faktor darf nicht 0 oder negativ sein!"
- negativer Faktor für Gehaltserhöhung -> "Faktor darf nicht 0 oder negativ sein!"
- char für Gehaltserhöhung -> "Faktor darf nicht 0 oder negativ sein!"
- Mitarbeitersuche mit Name: keine Möglichkeit für falsche Eingaben gefunden
- Mitarbeitersuche mit Jahren der Betriebszugehörigkeit:
  - char Eingabe -> 0-jähriges Jubiläum wird angezeigt
  - float Eingabe -> wird zu int gekürzt
  - negative Zahl: Vorzeichen wird ignoriert

Bekannte Fehler:
- bei ungültigen Eingaben wird das Menü nochmal mit dem Fehler "Ungültige Option" angezeigt, bevor man eine neue Option wählen kann
